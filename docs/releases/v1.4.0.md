# Bruno Browser v1.4.0

Esta versão melhora a primeira experiência após a instalação e permite gerar um diagnóstico seguro para suporte sem expor os dados das contas ou dos perfis.

## Novidades

- Guia de configuração inicial com quatro etapas ligadas ao estado real do aplicativo: sistema, Discord, plano e primeiro perfil.
- Abertura automática do guia em instalações incompletas e acesso manual em **Configurações**.
- Progresso calculado novamente quando o diagnóstico, a conta, a licença ou os perfis mudam.
- Prévia visual do onboarding disponível no frontend web, mantendo operações de disco e autenticação desabilitadas fora do aplicativo desktop.
- Exportação manual de relatório JSON para suporte usando o seletor nativo do Windows.
- Relatório com versão, arquitetura, estado dos subsistemas e inventário anônimo de perfis, DNS, rotas e extensões.
- Exclusão explícita de nomes e IDs de perfil, notas, páginas visitadas, Discord ID, conteúdo de keys, host, usuário e senha de proxy.
- Teste de regressão que tenta inserir dados sensíveis no perfil, proxy e log e confirma que nenhum deles aparece no arquivo exportado.
- Pipeline de release otimizado para executar apenas uma passagem LZMA final no instalador universal.

## Atualização

Quem possui a v1.2.0 ou posterior instalada pode usar **Atualizações > Baixar e instalar**. O aplicativo verifica o tamanho e o SHA-256 publicado pelo GitHub antes de iniciar a atualização e mantém o ponto de restauração da versão anterior até a nova interface confirmar a inicialização.

O instalador ainda não possui assinatura Authenticode comercial. O Windows SmartScreen pode solicitar uma confirmação do editor desconhecido, mesmo com o download íntegro.
